BUILD 001 / PORTFOLIO BUILD

POCKET GOAT

A bookstore/library-inspired cultural refuge in Constanța built around reading, conversation, local history and community programming — not a generic café with books as decoration.

CURRENT STATE / ACTIVE BUILD
01 / CHALLENGE

THE BUSINESS FIRST.

The website has to explain a hybrid place quickly: books, coffee, quiet reading, cultural events and community participation, while keeping the experience warm and coherent rather than looking like five unrelated businesses.

02 / DIRECTION

NO TEMPLATE LOGIC.

Dark green, wood and ivory; editorial warmth; library cues; strong cultural identity; dedicated spaces for programming, books and the Dobrogea/Constanța axis.

03 / SYSTEM

WHAT THE BUILD NEEDS TO DO.

Clear event architecture, programme discovery, books/content areas, community proposals, multilingual readiness and a structure that can grow without turning the homepage into one endless feed.

04 / LANGUAGES

MARKET READY.

Romanian and English are core candidates for the public experience, with architecture designed so additional languages can be added deliberately.
